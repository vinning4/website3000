// FAQ

  • How does the subscription work?

    Think Netflix, but with a web developer on retainer. One fixed monthly fee, cancel anytime.

    Unlike traditional web design, which usually means a large upfront fee and no support afterwards, the subscription spreads the cost and includes everything: hosting, edits, security and performance monitoring. One direct line to your developer, zero technical headaches.

  • What's the minimum subscription length?

    None. It's month to month from day one with no lock-in. Search visibility builds gradually, so staying a while helps, but that's entirely your call.

  • Do I need to know anything about websites?

    Nothing at all. I handle the technical side and explain things in plain English whenever you ask. You'll always know what's happening, and I'm reachable for any questions.

  • Why don't you use Squarespace, WordPress or Wix?

    Those platforms are built for everyone, so they're optimised for no one. They rely on off-the-shelf templates and add-on tools that pile up, need constant updating, and slow a site down over time. WordPress, in particular, is a frequent target for hackers.

    I code every site by hand, with only what it needs. There's nothing extra to slow it down, break, or be hacked. The result is a faster, leaner site, engineered for results. For a small business, this approach makes the most sense.

  • Can I make changes after it's live?

    Yes, edits are included on the subscription plan — just send a message and I'll handle it. If you'd rather manage things yourself, the one-time purchase option includes all source code files.
